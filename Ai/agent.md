# agent

## 核心概念
* Prompt Engineering（提示词工程）
  - 是什么：是你的“指令艺术”，负责把人类语言转化为AI能精准理解的命令
  - 本质：大模型是“概率预测机”，好的提示词能缩小它的“搜索空间”，让它聚焦在正确答案上。
  + 核心技术：
    - 角色扮演（如“你是一位资深Linux内核工程师”）。
    - Few-shot（少样本示例）（给一两个输入输出样例，让模型模仿）。
    - 结构化指令（使用XML或Markdown明确区分上下文、指令和输出格式）
* Context（上下文） 
  - 是AI的“工作记忆”，决定了它能看到什么、记住什么。
  - 包括系统提示词（固定人格）、对话历史、RAG（检索增强生成）召回的文档、当前打开的文件代码、甚至整个代码仓库的结构。
  - 限制：模型有上下文窗口（如128K、200K tokens）。一旦窗口塞满，早期信息会被“遗忘”。
* Tool Use（工具使用）
  - 是AI的“手脚”，让它能去执行外部操作（如读文件、运行命令）。
  - 本质：让AI从“纯文本顾问”变成“能动手干活的员工”。

* Workflow（工作流）
  - 是AI的“大脑决策系统”，决定了它如何规划、执行和验证一系列任务。
  - 现在的趋势：随着Claude Code、OpenAI Codex这类强自主智能体的崛起，Prompt Engineering的门槛在降低（因为AI自己能规划工作流），而Context的构建（RAG索引质量）和Tool Use的权限沙盒设计，正成为拉大工具差距的关键护城河。
