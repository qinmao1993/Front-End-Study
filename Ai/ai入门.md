# 人工智能入门
## AI 到底是什么？
  > 人工智能（AI）是让机器模仿人类智能的技术。它有很多子领域，我们最先接触的是 机器学习 和 深度学习。
  - 机器学习（Machine Learning：这是AI的核心基础，让计算机从数据中学习规律而不需要显式编程。包括监督学习（如分类、回归）、无监督学习（如聚类、降维）和强化学习。
  - 深度学习：一种更强大的机器学习方法，使用多层神经网络。它是当下图像识别、语音助手、聊天机器人（如 ChatGPT）背后的核心技术。

## 入门必备基础
* Python 是首选,语法简单，AI 生态最完善（TensorFlow, PyTorch, scikit-learn 等都支持）。 掌握基础语法、函数、循环、列表字典、条件判断、文件读写、NumPy 基础数组操作即可。
* 数学知识
  - 线性代数：向量、矩阵、点积（理解数据表示和神经网络运算）
  - 微积分：导数、梯度（理解模型如何“学习”——梯度下降）
  - 概率统计：均值、方差、正态分布、条件概率（理解数据分布和模型评估）

## 核心库与工具
* NumPy：数组与矩阵运算基础
* Pandas：数据清洗与处理（读取 CSV、筛选、分组）
* Matplotlib / Seaborn：数据可视化（画折线图、散点图等）
* Scikit-learn：传统机器学习算法库（线性回归、决策树、聚类等）

## AI的研究的方向
* 计算机视觉（Computer Vision）
  - 让机器“看懂”图像和视频，应用包括人脸识别、自动驾驶中的环境感知、医疗影像分析等。
  - OpenCV、经典 CNN 架构（ResNet、YOLO）

* 自然语言处理（NLP）
  - 让机器理解、解释和生成人类语言，涵盖聊天机器人、机器翻译、情感分析、文本生成等。
  - 学 RNN、Transformer、BERT，尝试做情感分析或文本生成

* 大语言模型应用
  - 学习 LangChain、提示工程，开发基于 GPT 的智能助手

## 硬件与开发环境
* 初期：普通笔记本电脑（CPU）完全够用，学习传统机器学习和小型深度学习毫无压力。
* 需要 GPU 时：可以使用 Google Colab（免费云 GPU/TPU，每月有一定时长），非常好用。
* 本地环境推荐：安装 Anaconda（管理 Python 环境和包）+ Jupyter Notebook 或 VS Code。
