# 机器视觉

## 前置知识
### 硬件
> 学习机器视觉需要扎实的硬件知识基础，因为硬件是获取和处理图像信息的物理载体，其选择直接影响系统的性能、精度、速度和成本
* 照明
  - 机器视觉的基石！好的照明方案能极大提升图像对比度、减少干扰、突出目标特征，甚至简化后续软件处理。差的照明会毁掉整个系统
  - 光源类型： LED（最常用，寿命长，稳定，可选多种颜色/形状）、卤素灯、荧光灯、激光（结构光、线激光）
  + 照明方式：
    - 正面照明： 环形光、条形光、同轴光（消除反光）、穹顶光（漫射均匀）
    - 背面照明： 背光源（突出轮廓、测量尺寸）
    - 结构光： 投射特定图案（如条纹、网格）用于3D重建
  + 颜色：白光、单色光（红、绿、蓝、红外、紫外）。选择与被测物颜色互补的光源能增强对比度（例如，用红光照射绿色物体）
  + 控制：亮度调节、频闪控制（与相机快门同步，用于高速或消除运动模糊）。
* 镜头
  - 作用：将场景光线聚焦到相机传感器上，形成清晰的图像。
  - 焦距：决定视场角和成像距离（工作距离）。短焦距广角，长焦距望远。
  - 光圈：控制进光量和景深。大光圈进光多、景深浅；小光圈进光少、景深大。
  - 接口：C口（最常见）、CS口（短法兰距）、F口（大靶面）、M口（微小镜头）。
  - 分辨率/MTF：镜头解析细节的能力，需要与相机传感器分辨率匹配（镜头分辨率应略高于传感器）。
  - 畸变：枕形畸变、桶形畸变，影响几何精度，需要软件校正或选择低畸变镜头。
  - 远心镜头：特殊镜头，成像大小不随物距变化，用于高精度尺寸测量，消除透视误差。
  - 变焦镜头：焦距可调，灵活性高，但精度和稳定性通常不如定焦镜头。
* 相机
  - 核心传感器：将光信号转换为电信号。
  + 传感器类型：
    - CCD：成像质量好、噪声低、灵敏度高（尤其弱光），但速度相对慢、功耗高、成本高
    - CMOS：速度快、功耗低、成本低、集成度高（片上集成ADC等），现在主流，性能已大幅提升接近甚至超越CCD。
  + 快门类型：
    - 全局快门：所有像素同时曝光。绝对必需 用于拍摄运动物体，无运动模糊。
    - 卷帘快门：像素逐行曝光。成本低，但拍摄运动物体会产生果冻效应（倾斜、变形）。
  - 分辨率：传感器像素数量（如 1920x1080, 5MP, 12MP）。不是越高越好，需结合视场大小和检测精度要求计算所需分辨率。 
  - 像素尺寸: 影响感光能力和动态范围。大像素感光好，小像素分辨率密度高。
  + 接口：
    - GigE Vision：以太网接口，传输距离长（可达100米），带宽适中（1Gbps/10Gbps），成本低，广泛应用。
    - USB3 Vision：即插即用，带宽高（5Gbps），传输距离短（<5米），成本低，适合桌面应用。
    - Camera Link：高速（可达850MB/s），低延迟，传输距离短（<10米），需要专用采集卡，成本较高。
    - CoaXPress：单根同轴电缆实现高速数据传输（可达12.5Gbps/lane）、供电和通信，距离较长（>40米），扩展性强，是Camera Link的强力替代者。
    - MIPI CSI-2：主要用于嵌入式系统（如树莓派、手机）。
* 图像采集卡
  - 作用 对于Camera Link、CoaXPress、模拟相机等接口，需要专门的采集卡将相机的高速图像数据传输到计算机内存中。随着GigE Vision和USB3 Vision的普及，许多系统不再需要单独的采集卡。
* 处理平台
  - 作用：运行图像处理算法和视觉软件的“大脑”。
  - 工控机：最常见的平台，性能强大，扩展性好。需关注CPU性能（多核高频）、内存容量（越大越好）、存储（SSD加速）、扩展槽（用于采集卡、GPU等）
  - 嵌入式平台：如 ARM 开发板（树莓派、NVIDIA Jetson系列）、FPGA、专用视觉控制器。体积小、功耗低、集成度高，适合空间受限或边缘计算场景。Jetson等平台内置强大GPU，适合运行深度学习模型。
  - 操作系统: Windows（常用，软件生态丰富）、Linux（稳定，开源工具多，嵌入式常用）、实时操作系统（RTOS，用于超高实时性要求）。

## 视觉的核心任务
* 图像分类
  - 关键技术：卷积神经网络（CNN），代表模型：AlexNet（2012年突破）、ResNet（残差网络）
* 目标检测
  - 主流算法：YOLO系列（You Only Look Once）：实时检测（如YOLOv8检测速度达100FPS）
  - Faster R-CNN：高精度但速度较慢
* 图像分割
  - 对图像中每个像素进行分类（如区分“人”“天空”“道路”）
  - 代表模型：U-Net（医疗影像）、Mask R-CNN（实例分割）。
* 关键点检测（Keypoint Detection）
  - 定位物体关键点（如人脸五官、人体关节）
  - 人脸识别（68点模型）、姿态估计（OpenPose检测人体17个关键点）。

## 底层技术：如何让机器“看”懂图像？
* 图像预处理
  - 去噪（高斯滤波）
  - 灰度化（减少计算量）
  - 归一化（将像素值缩放到[0,1]区间）
* 特征提取 
  > 从像素到高级语义
  + 传统方法（2010年前主流）：
    - SIFT（尺度不变特征）、HOG（方向梯度直方图）
  + 深度学习方法（现代主流）：
    - 卷积层（Convolutional Layer）：用滤波器提取局部特征（如边缘、纹理）
    - 池化层（Pooling Layer）：降低特征图尺寸（如最大池化保留显著特征）。

## 相关框架和库
* OpenCV
* 后端推理框架
  > 构建和训练模型用
  + TensorFlow
    - 特点: 开源，广泛使用的深度学习框架，提供了用于构建和训练人脸识别模型的工具。
    - 推理库: TensorFlow Lite（用于移动和嵌入式设备）和 TensorFlow Serving（用于大规模部署）
  + PyTorch
    - 特点: 开源，支持动态计算图，具有灵活性和易于调试的特点。
    - 推理库: TorchServe（用于模型的部署和推理）和 TorchScript（用于将模型转换为优化的推理格式）
  + ONNX Runtime
    - 特点: 开源，支持多种深度学习框架的模型，提供高效的推理性能。
    - 支持框架: 支持 ONNX（Open Neural Network Exchange）格式的模型，这些模型可以由 TensorFlow、PyTorch 和其他框架转换而来
  + MXNet
    - 特点: 开源，支持分布式训练和高效的推理。
    - 推理库: Apache MXNet 提供了高效的推理功能，支持多种硬件加速
  + OpenVINO
    - 特点: 英特尔提供的开源工具包，优化了在英特尔硬件（如 CPU、GPU、VPU）上的推理性能。
    - 支持框架: 可以将 TensorFlow、PyTorch 等框架的模型转换为 OpenVINO 格式
  + TensorRT
    - 特点: NVIDIA 提供的高性能推理优化库，专为 NVIDIA GPU 设计。
    - 支持框架: 支持从 TensorFlow、PyTorch 和其他框架转换的模型，通过优化加速推理过程
