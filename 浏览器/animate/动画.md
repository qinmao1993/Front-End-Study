# 浏览器中的动画
浏览器中的动画技术是前端开发的重要组成部分，能够提升用户体验和交互性

## css 动画
* CSS Transitions（过渡）
  - 原理：在元素状态变化时（如悬停、聚焦）自动触发平滑过渡效果。
  + 语法：transition: 过渡属性    过渡时长    过渡延迟   缓动函数
    - transition-property：指定过渡属性（如 all, opacity, transform）。
    - transition-duration：过渡时长（如 0.3s）。
    - transition-delay：延迟时间。
    - transition-timing-function：缓动函数（如 ease-in-out）。
  + 过渡事件：transitionend
     ```js
        element.addEventListener('transitionend',()=>{
            // do something
        })
     ```
  + 示例：
    ```css
        .box {
            transition: transform 0.3s ease-in-out;
        }
        .box:hover {
            transform: scale(1.1);
        }
    ```
  - 优点：简单易用，性能优化（GPU 加速）。
  - 缺点：仅控制开始和结束状态，无法实现复杂中间过程。
* CSS Keyframes（关键帧动画）
  - 原理：通过 @keyframes 定义动画序列，支持多阶段控制。
  - 语法：animation:  @keyframes名, 时长, 缓动函数, 延迟, 循环次数（如 infinite）, 播放方向（如 alternate、reverse）, 播放状态（backwards、forwards、none）
  - 示例
  ```css
    /*  定义动画  */
    @keyframes slide {
        0% { transform: translateX(0); }
        100% { transform: translateX(100px); }
        /*  或使用
        from{
            transform: translateX(0);
        },
        to{
            transform: translateX(100px);
        } 
        */
    }
    .box {
        animation: slide 2s ease infinite;
    }

    /*  动画暂停和播放  */
    .box {
        animation: slide 2s ease infinite paused;
    }
    .box:hover{
      animation-play-state:running;
    }

  ```
  - 优点：支持循环、自动播放和复杂动画序列
  - 缺点：动态控制能力较弱（需配合 JS）
  - 事件：animationend

## js 动画
### 原生api
* requestAnimationFrame (RAF)
  > 现代浏览器提供的一个用于执行动画的 API。它告诉浏览器——你希望执行一个动画，并且要求浏览器在下次重绘之前调用指定的回调函数来更新动画。该方法自 2011 年左右被广泛采用，现已成为创建流畅、高效动画的标准方式。
  + 为什么需要 RAF?
   > 在 RAF 出现之前，开发者通常使用 setTimeout 或 setInterval 来实现动画。这些方法存在几个问题：
    - 时机不可控：即使设置了理想的间隔（如 16.7ms 对应 60fps），这些定时器也可能会被其他任务阻塞，导致动画卡顿。
    - 不必要的开销：即使页面处于未激活的标签页中，定时器依然会持续运行，浪费资源。
    - 与浏览器绘制不同步：定时器回调的执行时机与浏览器的绘制周期无关，可能导致额外的布局和绘制，甚至丢帧。

  + RAF 正是为了解决这些问题而生的：
    - 与浏览器绘制同步：回调会在浏览器每次重绘之前执行，保证了动画的流畅性。
    - 节省资源：当页面处于后台或隐藏状态时，浏览器会暂停 RAF 的调用，从而节省 CPU 和电池。
    - 性能优化：浏览器可以对同一帧内的多个 RAF 回调进行合并，减少重排和重绘。

  + 工作原理
    - 浏览器通常每秒刷新屏幕 60 次（60Hz），即每帧大约 16.67 毫秒。RAF 的回调函数会在下一次屏幕重绘之前被调用，因此开发者可以在回调中更新动画状态，然后浏览器会在同一帧内完成绘制。

  + 基本用法
    - callback：下一次重绘之前要执行的回调函数。该函数会被传入一个参数，即一个 DOMHighResTimeStamp 类型的时间戳，表示从页面加载开始到当前回调被触发时经过的时间。这个时间是由浏览器的性能时钟提供的，与 performance.now() 返回值一致。。该时间戳可用于计算动画的进度，以实现与时间相关的动画，保证不同刷新率设备上速度一致。
    - 返回值：一个整数，表示该回调的唯一标识符。可以将此 ID 传递给 cancelAnimationFrame 来取消回调。
   ```js
    requestID = requestAnimationFrame(callback);
    // cancelAnimationFrame(requestID); // 取消该帧的执行
   ```

* Web Animations API (WAAPI)
  > 是现代浏览器提供的一套原生 js 接口，用于直接在脚本中创建、控制和编排动画。它将 CSS 动画/过渡的强大表现力与 js 的灵活性结合起来，旨在统一 Web 平台上分散的动画模型（CSS 动画、CSS 过渡、SMIL 动画），为开发者提供一种更高效、更一致的方式来构建高性能动画。
  + 为什么需要 WAAPI？
    > 在 WAAPI 出现之前，Web 动画主要通过以下方式实现：
    - CSS 过渡/动画：声明式，简单高效，但难以动态控制（暂停、反向、跳转）和组合复杂序列。
    - requestAnimationFrame：命令式，极其灵活，但需要手动管理每一帧的状态、性能开销大，且容易出错。
    - SMIL（已逐步淘汰）：主要用于 SVG，语法复杂，浏览器支持不一致。
    > WAAPI 填补了声明式和命令式之间的空白，既提供了 CSS 动画的性能（运行在合成线程），又提供了 js 的动态控制能力。
  + 核心概念与接口
    > WAAPI 的核心模型围绕两个主要对象：动画 (Animation) 和 效果 (KeyframeEffect)，以及一个时间线 (Timeline)
    - KeyframeEffect 描述动画的关键帧和时序选项（时长、缓动、迭代次数等）。它定义了“动画应该变成什么样”以及“动画应该持续多久”
    - Animation 负责播放控制和时间管理。它接收一个 KeyframeEffect，并将其与一个 AnimationTimeline（通常是文档的时间线 document.timeline）关联起来，然后提供 play()、pause()、reverse() 等方法。
  + 基本用法
    ```js
        // 方式1. 直接在元素上创建并返回一个 Animation 对象。
        const element = document.querySelector('.box');
        // 定义关键帧
        const keyframes = [
            { transform: 'translateX(0)', background: 'red' },
            { transform: 'translateX(100px)', background: 'blue' }
        ];
        // 定义时序选项
        const options = {
            duration: 1000,        // 毫秒
            easing: 'ease-in-out',  // 缓动函数
            iterations: Infinity,   // 无限循环
            direction: 'alternate'  // 往返运动
        };
        // 创建并自动播放动画
        const animation = element.animate(keyframes, options);

        // 方式2. 显式创建 KeyframeEffect 和 Animation
        // 当需要更精细的控制（例如复用效果、组合多个动画）时，可以分开创建：
        const element = document.querySelector('.box');
        // 创建关键帧效果
        const effect = new KeyframeEffect(
            element,
            [
                { transform: 'scale(1)', opacity: 1 },
                { transform: 'scale(1.5)', opacity: 0.5 }
            ],
            {
                duration: 800,
                easing: 'cubic-bezier(0.42, 0, 0.58, 1)',
                fill: 'forwards'   // 动画结束后保持最后状态
            }
        );
        // 创建动画对象，并与默认时间线关联
        const animation = new Animation(effect, document.timeline);
        // 手动启动
        animation.play();
    ```
  + 关键帧格式
    ```js
        // 数组形式：明确每个关键帧的位置。如果不指定 offset，浏览器会自动均匀分布。
        [
            { offset: 0, transform: 'translateX(0)' },
            { offset: 0.3, transform: 'translateX(30px)' },
            { offset: 1, transform: 'translateX(100px)' }
        ]
        // 对象形式：用属性名组织关键帧值（类似 CSS 关键帧）。
        {
            transform: ['translateX(0)', 'translateX(100px)'],
            background: ['red', 'blue'],
            offset: [0, 1]      // 可选，与值一一对应
        }
    ```
  + 时序选项：options 对象支持 CSS 动画中几乎所有属性，以及一些额外的控制：
    - duration	单次迭代时长（毫秒）	默认 0
    - iterations	迭代次数，可为 Infinity 默认 1
    - easing	缓动函数，如 'linear', 'ease-in', cubic-bezier(...) 默认 'linear'
    - direction	'normal', 'reverse', 'alternate', 'alternate-reverse' 默认 normal
    - fill	动画开始前和结束后的样式应用：'none', 'forwards', 'backwards', 'both' 默认 'none'
    - delay	延迟开始时间（毫秒）     默认 0
    - iterationStart	从第几次迭代的什么位置开始（如 0.5 表示从第一次迭代的一半开始） 0
    - composite	与现有样式的合成方式：'replace', 'add', 'accumulate'  默认'replace'
  + 动画控制
    ```js
    const anim = element.animate(keyframes, options);
    // 播放
    anim.play();

    // 暂停
    anim.pause();

    // 反向播放（从当前时间点反向）
    anim.reverse();

    // 跳转到特定时间点（毫秒）
    anim.currentTime = 500;

    // 调整播放速率（负值表示反向）
    anim.playbackRate = 2;  // 2倍速

    // 结束动画（触发 finish 事件，并跳到结束状态）
    anim.finish();

    // 取消动画（移除效果，不再影响元素）
    anim.cancel();
    ```
  + 事件监听
    ```js
        anim.onfinish = (event) => {
            console.log('动画完成', event);
        };
        anim.oncancel = (event) => {
            console.log('动画被取消', event);
        };
        // 或使用 addEventListener
        anim.addEventListener('finish', (event) => { ... });
    ```
  + 获取页面上的所有动画
    - document.getAnimations() 返回当前文档中所有活动的 Animation 对象数组。这对于批量控制非常有用：
    - 也可以获取特定元素上的动画：element.getAnimations()。
    ```js
        // 暂停所有动画
        document.getAnimations().forEach(anim => anim.pause());
        // 移除所有动画
        document.getAnimations().forEach(anim => anim.cancel());
    ```

### 传统方法（已不推荐）
* setTimeout/setInterval
  - 问题：易导致丢帧、主线程阻塞，性能差。

## svg 动画
* CSS/JS 驱动：
  - 适用场景：路径变形、图标动画，适合矢量图形。
  ```html
    <svg>
        <circle cx="50" cy="50" r="40" class="pulse" />
    </svg>
    <style>
    .pulse {
        animation: scale 2s infinite;
    }
    </style>
  ```

## Canvas 动画
* 原理：通过 JS 逐帧绘制位图，适合游戏和数据可视化
* 示例
  ```js
    function draw() {
        ctx.clearRect(0, 0, canvas.width, canvas.height);
        ctx.fillRect(x, y, 50, 50);
        x += 1;
        requestAnimationFrame(draw);
    }
    draw();
  ```
* 优化技巧：
  - 离屏 Canvas 预渲染
  - 避免频繁重绘，分层绘制


## 动画库推荐
* GSAP (GreenSock)：
  - 被誉为“动画界的瑞士军刀”
  - 功能强大，支持时间轴、物理动画，兼容性好
* Anime.js
  - 轻量级，支持 CSS、SVG、DOM 属性
* Lottie
  - 设计师可将After Effects动画通过插件导出为JSON文件，开发者直接使用Lottie库渲染
  - 适用：App启动页、加载动画、复杂图标等追求高保真设计的场景。
* Animate.css
  - 最流行的CSS动画库之一，内置了超过60种预设动画效果

## 性能优化
* 减少重排（Reflow）：优先使用 transform 和 opacity（触发 GPU 加速）。
* 硬件加速：
  ```css
    .element {
        will-change: transform; /* 提前通知浏览器优化 */
    }
  ```
* 图层管理:避免过多图层（z-index 滥用），使用 translateZ(0) 提升图层
* 防抖/节流：控制滚动、拖拽事件的触发频率
