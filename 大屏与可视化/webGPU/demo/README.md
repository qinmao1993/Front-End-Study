WebGPU 交互演示

说明（中文）:

- 目的：演示 WebGPU 常见用法并提供交互：请求 Adapter/Device、缓冲区、纹理上传、渲染管线、计算着色器、缓冲区读回等。
- 运行要求：支持 WebGPU 的浏览器（Chrome/Edge 最新版本或 Canary）。建议通过本地静态服务器打开：
  - python3 -m http.server 8000
  - 或者使用任一静态服务器工具
- 使用方法：
  1. 通过浏览器打开 http://localhost:8000
  2. 点击「请求设备」以获得 GPU 访问权限
  3. 在示例下拉中选择想要的示例并点击「开始」
  4. 对于纹理示例，可上传图片文件查看效果；对于计算示例，可点击「读回粒子」查看 GPU 计算结果

文件：
- index.html - 页面与 UI
- style.css - 简单样式
- app.js - 主逻辑，代码中包含大量中文注释，说明每一步用法

注：WebGPU 仍在快速发展，不同浏览器/版本在细节（例如纹理格式、API 名称、性能）会有所不同。若出现不可用的 API，请尝试更新浏览器或参考 chromium 的 WebGPU 实现说明。
