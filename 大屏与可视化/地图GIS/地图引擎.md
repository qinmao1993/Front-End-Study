# 地图引擎
 商业的如百度、高德、谷歌，免费开源的leaflet、OpenLayers、mapbox、cesium

## Leaflet
> 轻量级、简单易用的开源 2D 地图库

## OpenLayers
> 功能强大、开源 2D/2.5D 地图库,比 Leaflet 有更丰富的开箱即用功能（如高级投影支持、丰富的格式解析、更复杂的交互控件、动画等）学习曲线稍陡峭。

## maplibre-gl(推荐)
> 基于 WebGL 的现代、高性能、高度可定制化的 2D/3D 地图渲染库
* 特性
  - 支持地图瓦片上叠加各种图层，支持 geojson、图片、文本 等多种信息在图层上进行加载显示
  - 支持自定义 Style （矢量瓦片）
  - 支持 2.5D 视角旋转及显示，支持加载 3D 模型
  - 支持通过 DOM 的方式添加 HTML 元素
  - 支持 web-gl 能力进行图形渲染
  - 支持进行 3D 形式的球星地理渲染和星空背景渲染
* maplibre-gl是 mapbox-gl 仓库 fork 出来的开放版本
  - 无需 accessToken 就能使用 mapbox-gl 的强大能力
  - 选择：如果你希望使用 Mapbox 官方提供的瓦片服务，那选 mapbox-gl，如果你只是希望使用其地图引擎的相关能力，并不打算使用 Mapbox 官方的瓦片服务，可选 maplibre-gl 
  - (maplibre-gl-js)[https://github.com/maplibre/maplibre-gl-js]

## cesium（3D场景推荐）
> 专业的开源地理空间平台和 3D 地球/地图引擎。专注于高精度、大范围、时序性的 3D 地球可视化（包括全球地形、3D Tiles、KML、CZML、WMS/WMTS、卫星影像、点云等），适用于复杂的 GIS、仿真、航天等领域。
