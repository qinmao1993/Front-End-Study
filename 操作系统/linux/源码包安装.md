# 源码编译安装通用步骤

## 通用步骤
1. 准备工作：确保系统已安装编译工具链（如 gcc、g++、make）和依赖库的头文件。
  ```bash
   # 在 CentOS/RHEL 上
   yum groupinstall "Development Tools" 

   # 在 Debian/Ubuntu 上
   apt install build-essential
  ```

2. 下载并解压源码：从官方或可信源获取源码压缩包（通常为 .tar.gz 或 .tar.bz2 格式），保存到合适目录（如 /usr/local/src）。
  ```bash
    # 下载源码包
    wget https://registry.npmmirror.com/binary.html?path=python/3.10.14/Python-3.10.14.tgz
    # 传输安装包到目标 CentOS 主机,使用工具如 scp 或者将包拷贝到可访问的共享目录中。
    scp Python-3.10.14.tgz username@centos_host:/path/to/destination

    # 3. 解压源码包,通常建议解压到 /usr/local/src 或者用户偏好的目录下。
    tar -zxvf Python-3.10.14.tgz
    cd Python-3.10.14

    # 其他压缩格式解压
    tar -zxvf package.tar.gz      # 解压 .tar.gz
    tar -jxvf package.tar.bz2     # 解压 .tar.bz2
    tar -xvf package.tar.xz       # 解压 .tar.xz（可能需要 xz 工具）

    # 解压后会生成一个同名目录，进入该目录：
    cd package-version
   ```

3. 阅读文档
  - 必做步骤：查看 README、INSTALL 或 docs/ 目录下的说明文件，了解软件的特殊依赖、编译选项和注意事项。
  ```bash
    less README
    less INSTALL
  ```

4. 配置编译参数（配置阶段）
  - 大多数软件使用 configure 脚本（由 Autoconf 生成）来检测系统环境并生成 Makefile。执行：
   ```bash
    ./configure --prefix=/usr/local/package-name
   ```
  - --prefix 指定安装路径，默认通常是 /usr/local,建议为每个软件设置独立前缀（如 /opt/软件名）以便管理。
  - 其他常用选项：--enable-xxx、--with-xxx 可开启/关闭特定功能。
  - 若使用 CMake 构建，则运行 cmake 并指定参数（如 cmake .. -DCMAKE_INSTALL_PREFIX=/usr/local）。
  - 若缺少依赖，configure 会报错，需根据提示安装相应开发包。
  - 示例
    ```bash
        mkdir /usr/local/python3.10.14
        # --enable-optimizations 它会为 Python 启用一些优化以提高其性能
        ./configure --enable-optimizations CFLAGS="-std=c11"  --prefix=/usr/local/python3.10.14
    ```

5. 编译源码
  - 执行 make 命令，根据 Makefile 规则编译,可使用 -j 参数加速（如 make -j4 用4个核心编译）。
  - 若编译出错，检查错误信息，通常为依赖缺失或版本不兼容。
   ```bash
    # 对于 macOS，使用 sysctl -n hw.ncpu 获取 CPU 核心数
    # centos cat /proc/cpuinfo | grep processor | wc -l
    make -j$(sysctl -n hw.ncpu) 
   ```

6. 安装软件
   - 编译成功后，将生成的文件复制到指定安装目录，通常需要 root 权限：
   - 若 --prefix 指定为用户有写权限的目录（如 $HOME/local），则无需 sudo。
   ```bash
    # altinstall 是为了避免覆盖系统默认的 Python 版本
    make install 

    # 验证安装
    /usr/local/python3.10.14/bin/python3 --version
   ```

7. 后续配置：配置环境变量，使其能够全局访问到新安装的可执行文件
  ```bash
    # 方式一：修改当前用户的配置文件（仅对当前用户有效）编辑 .bashrc 或者其他 Shell 配置文件，添加如下行（假设您选择了 /usr/local/python3.x.x 作为安装路径）：
    export PATH=/usr/local/python3/bin:$PATH
    # 然后执行 source ~/.bashrc 使配置立即生效。

    # 或者也可以用软连接的形式，类似windows 的快捷方式
    sudo ln -s /usr/local/python3.10.14/bin/python3 /usr/bin/python3

   # 验证是否成功
    python3 -V
  ```
