# 开发中常见的问题

## MySQL为什么不推荐用 Docker 部署？
* 问题一：DB有状态，不方便扩容
  - 有状态容器 需要使用数据卷（Volumes）、绑定挂载（Bind Mounts）或网络存储等方式将数据持久化到宿主机或外部存储设备上，确保数据在容器的生命周期之外也能保存
  - 有状态容器扩容复杂。需要考虑数据的一致性和分布问题，宿主机的数据文件是容器独占的，无法实现两个容器实例共享一份数据文件。
* 问题二：docker 的资源隔离不彻底
  - Docker只是限制资源消耗的最大值，而不能隔绝其他程序占用自己的资源。
  - Docker 并没有真正、彻底的隔离CPU、内存。
  
* 问题三：docker 不适合磁盘io密集型的中间件
