# 线性代数-最核心
AI中的数据结构（向量、矩阵、张量）都源于此，神经网络本质上是大量的矩阵乘法。
必学概念：向量、矩阵、张量；矩阵乘法、转置、逆；特征值与特征向量；范数；点积
在AI中的作用：数据表示（图像=像素矩阵，文本=词向量）、神经网络层的计算、反向传播中的梯度传递

## 什么是线性代数，他解决的是什么问题？
* 概念
  - 线性代数是研究向量、向量空间（线性空间）、线性变换以及线性方程组的数学分支。通俗地说，它研究的是“直线性”的关系——不涉及曲线、平方、指数等非线性部分。
* 核心思想
  - 把“批量数据”和“变换”用统一的方式处理
* 为什么叫“线性”？
  - 直观理解：输入加倍，输出也加倍；输入叠加，输出也叠加。
  - 代数是指用符号和运算规则来推演。

## 向量
* 概念：向量就是一列/一行数字，用来表示一个东西的多项属性。
  + 例子：你买奶茶：大杯（1）、加珍珠（1）、加椰果（0）、少冰（1）。
    - 向量 = [1, 1, 0, 1]（分别对应：大小、珍珠、椰果、少冰）
    - 另一个顾客：[0, 0, 1, 0]（中杯、无珍珠、加椰果、正常冰）
    - 直观：向量就像超市里的商品特征卡。多个向量放在一起，就是一个数据集（Excel表格的一行就是一个向量）。

## 矩阵
* 概念：矩阵是矩形的数字阵列（行和列）。它可以代表：
  - 一堆向量（多行数据）
  - 一种操作（把输入向量变成输出向量）
  + 例子
    - 在计算机里，图片是像素矩阵，把一张图片旋转90度，可以用另一个矩阵与它相乘来实现。就像一个“滤镜”模具：输入原矩阵，输出旋转后的矩阵。
* 矩阵乘法
  - 概念：把一个矩阵当“操作指令”，另一个矩阵当“待处理数据”，相乘就是批量执行指令。
  + 例子（不讲公式，讲生活类比）：
    - 工厂A把“面粉、鸡蛋、糖”变成“蛋糕、饼干”工厂B把“蛋糕、饼干”变成“销售额、利润”。
    - 要计算“从原料直接到最终结果”，就把工厂A的操作表和工厂B的操作表“乘”起来，得到一张新表（原料→销售额/利润）。
  + 具体例子（数字简化）：
    - 你买水果：苹果2个，香蕉3根。
    - 单价：苹果5元/个，香蕉4元/根。
    - 总价 = 2×5 + 3×4 = 22元。
    - 这里，[2, 3]（数量向量）乘以 [[5],[4]]（价格矩阵）得到总价。乘法的本质是“对应相乘再求和”。
  - 在AI中：神经网络的每一层就是：输入向量 × 权重矩阵 + 偏置向量。矩阵乘法把输入数据批量转换成输出。

## 线性变换
  - 通过矩阵“乘以”向量，实现旋转、缩放、投影、映射等操作（且保持直线和平行线不变）。
  - 在计算机图形学中，你移动手机屏幕上的图片（放大、旋转），背后就是一个线性变换矩阵在乘法运算。

## 点积
* 概念：两个向量对应位置相乘再求和。结果是一个数字。
  - 例子：用户A对三部电影的评分：[5, 1, 4]（《阿凡达》《小时代》《教父》）用户B的评分：[4, 2, 5]
  - 点积 = 5×4 + 1×2 + 4×5 = 20 + 2 + 20 = 42
  > 意义：分数越大，说明两人口味越相似（用于推荐系统）。如果两个向量方向相同（评分完全成比例），点积大；如果正交（毫不相关），点积为0。
