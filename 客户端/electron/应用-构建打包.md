# 应用构建打包

## electron-builder
* ![打包](./imgs/构建.png)
* electron-builder 打包过程
  - 收集配置信息：如图标、应用名、应用id、附加资源，没有使用默认的
  - 安装依赖
  - 生成asar
  - 准备二进制文件
  - 准备附加资源
  - 修改可执行程序：修改 electron.exe 如图标、应用名、应用id、附加资源
  - 应用签名：如果指定了签名信息，会使用 winCodeSign 的工具来为可执行文件签名，目的是防止分发时被篡改
  - 压缩资源
  - 生成卸载程序
  - 生成安装程序

## 安装包体积优化
* 拆包看体积分布
  ```bash
    du -sh dist dist-electron node_modules
    du -sh "YourApp.app/Contents/Resources"/*

    # 查大体积 sourcemap
    find . -name "*.map" -size +5M -print

  ```
* 安装electron到dev依赖下
  ```bash
    npm install electron -D
  ```
  ```json
    "build":{
        "electronDownload": {
            "cache": "./cache/electron"
        }
    }
  ```
* 语言优化
  ```json
    "build":{
        "electronDownload": {
            "cache": "./cache/electron"
        },
        "electronLanguages": [
            "zh-CN"
        ]
    }
  ```
* 发布版本别带 SourceMap
