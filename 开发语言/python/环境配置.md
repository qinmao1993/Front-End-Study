  - 方式二：homebrew 安装
* centos
  - 方式一(yum)： 
    ```bash
        # 1. 更新系统,首先确保您的系统已经更新到最新状态：
        sudo yum update

        # 2. 查看可用的 Python 版本
        sudo yum search python3

        # 3. 选择要安装的 Python 版本后，使用 yum 安装：
        # yum 会自动安装 Python 所需的依赖包，并将 Python 安装到系统默认路径中。
        sudo yum install python3

        # 4. 验证安装
        python3 --version

        # yum 离线安装
        # 这将下载 Python 3.12.4 及其依赖的 RPM 包到当前目录。
        yumdownloader --resolve --destdir /home/rpm python3.10
        # 拷贝到离线机器上
        cd /home/rpm

        # 使用 yum 安装软件包，这将安装当前目录下的所有 RPM 软件包。yum 会解决依赖关系并进行安装
        sudo yum localinstall *.rpm

    ```
   - 方式二：源码安装
     ```bash
       # 依赖准备：系统已经安装了必要的构建工具和依赖项：
       # 详情查看 https://docs.python.org/zh-cn/3/using/configure.html
       # 3.12 环境依赖
       # 1）OpenSSL 1.1.1 或更新版本
       # 2）在 Windows 上，需要 Microsoft Visual Studio 2017 或更新版本
       # 3）c11编译器

        yum install dnf-plugins-core  # install this to use 'dnf builddep'
        yum builddep python3

        yum -y install zlib-devel bzip2-devel openssl-devel ncurses-devel sqlite-devel readline-devel tk-devel

       # 1. 下载 Python 包
       wget https://registry.npmmirror.com/binary.html?path=python/3.12.4/Python-3.12.4.tgz

       # 2. 传输安装包到目标 CentOS 主机,使用工具如 scp 或者将安装包拷贝到可访问的共享目录中。
       scp Python-3.12.4.tgz username@centos_host:/path/to/destination

       # 3. 解压源码包,通常建议解压到 /usr/local/src 或者用户偏好的目录下。
       tar -zxvf Python-3.12.4.tgz
       cd Python-3.12.4

       # 4. 配置安装目录 注意：preadv2 需要 ： glibc glibc 2.20 版本中引入， ldd --version 查看 glibc 的版本
       mkdir /usr/local/python3.12.4
       # --prefix 的路径来改变安装目录 --enable-optimizations 它会为 Python 启用一些优化以提高其性能
       ./configure --enable-optimizations CFLAGS="-std=c11"  --prefix=/usr/local/python3.12.4

       # 5. 开始编译成可执行程序
       #  对于 macOS，使用 sysctl -n hw.logicalcpu 获取 CPU 核心数
       # centos cat /proc/cpuinfo | grep processor | wc -l
       # 注意：报错之后，make clean 之后重新编译
       make -j$(sysctl -n hw.logicalcpu)  

       # altinstall 是为了避免覆盖系统默认的 Python 版本
       make altinstall

       # 5. 验证安装
       /usr/local/python3.12.4/bin/python3 --version

     ```

## 虚拟环境(Venv)
> 每个项目隔离依赖，类似 node_modules ,Python 3.3+ 自带 venv 模块。
```bash
    # 创建虚拟环境（会在当前目录生成一个 .venv 文件夹）
    python -m venv .venv

    # 激活（Linux/macOS）
    source .venv/bin/activate

    # 激活（Windows 命令提示符）
    .venv\Scripts\activate

    # 激活（Windows PowerShell）
    .venv\Scripts\Activate.ps1

    # 激活后，终端前面会出现 (.venv) 前缀，此时 pip install 的所有包都装在这个隔离环境里，退出用 deactivate。
    # Python 虚拟环境通常绑定到特定 Python 版本和系统架构，不应提交到 Git，只需在 .gitignore 里加 .venv。
```

## Python的版本管理pyenv(类似于nvm) 淘汰了
  ```bash
    brew install pyenv
    brew upgrade pyenv

    # pyenv的版本
    pyenv -v
    
    # 列出系统中安装的 python 版本
    pyenv versions 

    # 显示当前目录下采用的 python 版本
    pyenv version    
                                   
    # 查看 pyenv 可用的 python 版本
    pyenv install --list

    # 1. 下载到缓存文件下
    wget https://registry.npmmirror.com/-/binary/python/3.11.4/Python-3.11.4.tar.xz -P ~/.pyenv/cache/
    # 2. 安装指定的版本
    pyenv install 3.11.4

    # 删除指定版本
    pyenv uninstall 3.11.4

    # 在当前目录下设置 python 版本，则在该目录下运行的 python 都是 3.6.1 版本。
    pyenv local 3.6.1

    # 切换python版本
    pyenv global 3.11.4

  ```

## 包管理器
* pip——最基础的包安装器（类似 npm 的 install 功能，但没有 lockfile），python 默认包管理工具，从 PyPI 拉取包,只装 python 包
  ```bash
    # 更新 pip 版本
    pip install --upgrade pip

    # 安装包
    pip install requests # 安装最新
    pip install requests==2.6.0 # 安装特定版本的包
    pip install --upgrade requests # 升级到最新版本

    # 一个或多个要从虚拟环境中删除的包。
    pip uninstall xx1  xx2
    
    # 显示所有在虚拟环境中安装的包
    pip list 

    pip freeze > requirements.txt   # 导出所有已安装包及版本号
    pip install -r requirements.txt # 从文件批量安装
  ```

* uv（纯python项目推荐）
  > 目前最强的趋势是 uv（由 Astral 团队用 Rust 开发）。
  + 集成
    - Python 版本管理（取代 pyenv）
    - 虚拟环境管理
    - 极快的依赖解析与安装（比 pip/pip-tools 快 10-100 倍）
    - 锁定文件 uv.lock（跨平台确定性构建）
    - 构建与发布 PyPI 包
  + 安装
    ```bash
        curl -LsSf https://astral.sh/uv/install.sh | sh   # macOS/Linux
        # Windows: powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

        # 或
        brew install uv
        pip install uv
        uv -V
    ```
  + 常用命令
  ```bash      
    # 设置 Python 解释器（无需预装 Python！）
    uv python list             # 查看已安装版本
    uv python install 3.14     # 安装指定版本
    uv python uninstall 3.14

    uv venv --python 3.14      # 创建虚拟环境

    # 创建新项目（相当于 npm init）
    uv init my-app   # 生成：pyproject.toml：项目元数据和依赖声明、README.md、一个简单的 hello.py
    cd my-app

    # 添加依赖（开发和生产）
    # uv add 会自动更新 pyproject.toml 并创建/更新 uv.lock（保证所有依赖、子依赖的精确版本被锁定）。
    uv add fastapi uvicorn[standard]          # 生产依赖
    uv add --dev black ruff mypy pytest       # 开发依赖
    uv sync                                   # 相当于 npm ci

    uv remove xxx

    # 运行代码（无需手动激活虚拟环境）
    uv run  main.py

    # 构建与发布：把项目打包发布到 PyPI
    uv build             # 构建 wheel 和源码包
    uv publish           # 发布到 PyPI（需配置 token）
  ```

* Anaconda|miniconda（ai数据科学）

## 包换源
* pip 换源
  ```bash
    # 永久换源（全局生效）
    # Linux/macOS：编辑 ~/.pip/pip.conf
    # Windows：编辑 %APPDATA%\pip\pip.ini
  ```
  ```ini
    [global]
    index-url = https://pypi.tuna.tsinghua.edu.cn/simple
    [install]
    trusted-host = pypi.tuna.tsinghua.edu.cn
  ```
  + 常用的有镜像有
    - 清华大学镜像:https://pypi.tuna.tsinghua.edu.cn/simple/
    - 阿里云:http://mirrors.aliyun.com/pypi/simple/
    - 中科大镜像:https://pypi.mirrors.ustc.edu.cn/simple/ 
* uv 换源
  - uv 使用和 pip 相同的配置源,上面配置好uv 就会自动读取
  - 或者在项目 pyproject.toml 里指定：
  ```toml
    [tool.uv]
    index-url = "https://pypi.tuna.tsinghua.edu.cn/simple"
  ```
