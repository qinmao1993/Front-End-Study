## 汇编语言
> 汇编语言（Assembly Language）是一种低级编程语言，它直接对应于计算机的机器指令（二进制代码），但用助记符（如 MOV, ADD, JMP）代替了0和1，使得人类勉强可以读写。

## 汇编在编程语言层级中的位置
* 高级语言 → 编译器 → 汇编语言 → 汇编器 → 机器语言 → CPU执行

## 核心概念：指令、寄存器、内存
> 要理解汇编，必须了解计算机的三大核心组件（从汇编视角看）：
* CPU 寄存器
  - CPU内部极高速的临时存储单元（容量极小，通常几十到几百字节）。汇编代码大部分时间都在操作寄存器。比如 x86 架构有 EAX, EBX, ECX, EDX 等通用寄存器，还有 PC（程序计数器，指向下一条指令地址）、SP（栈指针）。
* 内存地址
  - RAM中的数据，访问速度比寄存器慢很多。汇编中访问内存通常用 [地址] 表示。例如 MOV AX, [1000h] 表示将内存地址 1000h 处的数据复制到寄存器 AX 中。
* 指令集
  > 每种CPU有自己的指令集（如 x86, ARM, RISC-V）。指令大致分几类：
  - 数据传输：MOV, PUSH, POP, LOAD, STORE
  - 算术逻辑：ADD, SUB, MUL, DIV, AND, OR, XOR
  - 控制转移：JMP（无条件跳转），JE / JZ（条件跳转），CALL（调用函数），RET（返回）
  - 输入输出：IN, OUT（直接与硬件端口通信）
  - 系统调用：INT, SYSCALL（请求操作系统服务）

## 具体例子：x86汇编 vs C语言
  - 假设我们执行 C 代码：int c = a + b;在 x86-64 汇编中（Intel 语法）
  ```assembly
    MOV EAX, [a]    ; 将变量 a 的值从内存加载到 EAX 寄存器
    ADD EAX, [b]    ; 将变量 b 的值加到 EAX 上 (EAX = a + b)
    MOV [c], EAX    ; 将 EAX 的结果存回内存中的变量 c
   ```

## c程序中运行汇编代码
    ```c
    #include <stdio.h>
    int main(void) {
        int src=1;
        int dst;
        asm ("mov %1, %0\n\t"
            "add $1, %0"
            : "=r" (dst)
            : "r" (src));
        printf("%d\n", dst);
    }
    ```
    
## 汇编的应用场景
* 逆向工程与安全分析
  - 病毒、恶意软件、破解补丁、漏洞利用（Exploit） —— 这些通常没有源代码，你面对的就是二进制文件，反汇编后得到汇编代码。不理解汇编，就无法分析恶意行为。
* 底层系统编程
  - 操作系统内核、Bootloader、嵌入式系统（尤其是资源极度受限的MCU，如1KB内存）、设备驱动 —— 这些场景需要直接操作寄存器、中断、内存映射I/O。C语言虽然也能做，但某些初始化代码必须用汇编。
* 性能极致优化
  - 如游戏引擎的数学库、音视频编解码器（x265）、加密算法（OpenSSL）。编译器已经非常聪明，但在特定情况下，手写汇编可以榨干CPU的每一点性能（如利用AVX-512向量指令、精准控制流水线）。
* 编译器与逆向工具开发
  - 编译器（如GCC, LLVM）的后端需要生成汇编代码；调试器、反汇编器、性能分析工具（perf）需要解析汇编。

## 常见汇编语言类型（不同CPU架构）
* x86/x86-64	台式机、服务器、笔记本	复杂指令集（CISC），指令变长，历史悠久，汇编语法分 Intel 和 AT&T 两种风格
* ARM	手机、平板、树莓派、嵌入式	精简指令集（RISC），指令定长（早期），省电，如今也有64位和复杂扩展
* RISC-V	新兴开源架构，教育与研究	极简设计，模块化，没有历史包袱
* MIPS	路由器、游戏机（PS1, PS2）、教学	经典的RISC，结构清晰，适合教学
* AVR	Arduino主板（ATmega328P）	8位微控制器，指令极少，适合极简应用

## 如何入门学习汇编？
1. 选择架构
  - 最佳入门：RISC-V 模拟器（如 spike 或 qemu-system-riscv32）或 ARM Cortex-M（使用 mbed 或 STM32）。
  - 经典教学：MIPS（使用 MARS 或 SPIM 模拟器）。
  - 如果必须学 x86：从16位实模式（如8086汇编）开始，比现代32/64位保护模式简单得多。
2. 学习工具
  - 模拟器：避免真机损坏风险。推荐 QEMU。
  - 调试器：GDB 配合 layout asm，或 x64dbg（Windows），或 radare2（命令行逆向工具）。
  - 汇编器：NASM（x86），GAS（GNU汇编器，跨架构），MASM（微软，Windows）。
3. 推荐资源
  - 《汇编语言》（王爽著）—— 经典的中文入门书，基于x86 16位，非常易懂。
  - MIT 6.004（Computation Structures）—— 从逻辑门到RISC-V汇编。
  - godbolt.org（Compiler Explorer） —— 写C代码，实时看编译器生成的汇编，绝佳学习工具。
