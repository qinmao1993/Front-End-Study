# CSS 中的单位
在 CSS 中，px、em、rem、%、vw、vh、vmin/vmax 都是用于定义尺寸的单位，但它们的计算方式和应用场景不同。以下是详细区别：

## px（像素）
* 定义：绝对单位，1px 表示屏幕上的一个物理像素点
* 特点：
  - 固定大小，不随其他元素变化
  - 在高分辨率屏幕上（如 Retina 屏），浏览器可能自动缩放（例如 1px 可能对应多个物理像素）
* 适用场景
  - 边框、固定尺寸元素（如图标）。

## em（相对父元素字体大小）
* 定义：相对单位，基于父元素的 font-size 计算。
  - 若自身 font-size 为 2em，则大小为父元素字体的 2 倍。
  - 用于其他属性（如 width）时，基于自身的 font-size。
* 注意：多层嵌套时可能产生复合效果（需谨慎）。
  ```css
    .parent {
        font-size: 16px;
    }
    .child {
        font-size: 1.5em; /* 16px * 1.5 = 24px */
        padding: 2em; /* 24px * 2 = 48px */
    }
  ```

## rem（相对根元素字体大小）
* 定义：相对单位，基于根元素（<html>） 的 font-size 计算。
  - 默认根字体为 16px（可修改）。

* 适用场景：响应式布局（字体、间距、尺寸等）。
  - 响应式布局指的是元素大小能根据屏幕大小随时变化

## % (百分比)
* 定义：相对单位，基于父元素的对应属性计算。
  - width: 50% → 父元素宽度的 50%。
  - font-size: 150% → 父元素字体的 1.5倍（等同于 1.5em）。
* 特点：依赖父元素尺寸，常用于流式布局。
* 适用场景：容器内元素的相对尺寸（如栅格系统）。

## vw/vh（视口宽度高度百分比）
* 定义：1vw = 视口宽度的 1%。
   - 视口宽度 1000px → 10vw = 100px。
* 特点：与视口直接关联，不受父元素影响。
  - 这里的视口（Viewport）指的就是浏览器可视化的区域，是 window.innerWidth / window.innerHeight的大小
* 适用场景：全屏轮播图、响应式字体。
* vmin / vmax（视口最小/最大边百分比）
  - 1vmin = 视口 较小边 的 1%（宽高中较小的值）确保元素在小视口中始终可见（如圆形按钮）。
  - 1vmax = 视口 较大边 的 1% 大视口中填充空间（如背景图）

## rpx（小程序专用）
  - 以iPhone 6为标准，物理像素750，分辨率 375。无论屏幕大小，都将屏幕分成750份，每份就是1rpx, 1rpx=0.5px=1pt
  - 优点：通过 rpx 设置元素和字体的大小，小程序在不同尺寸的屏幕下，可以实现自动适配。

## 物理像素
* 定义
  - 硬件级别的实际发光点，是显示设备的最小物理单元。
* 特点
  - 每个物理像素由红、绿、蓝（RGB）子像素组成
  - 出厂固定，不可变（如一块屏幕有 1920×1080 个物理像素）
  - 高密度屏（如 Retina 屏）物理像素更小更密集

## 逻辑像素
* 定义：软件层面的抽象单位，CSS 中使用的 px 单位。
* 特点：
  - 与实际物理像素无关，是虚拟参考单位
  - 用于保持跨设备视觉一致性（1个CSS像素在不同屏幕可能对应多个物理像素）
  - 由浏览器根据设备像素比（DPR）自动换算
  - 示例：width: 100px 在普通屏可能是100个物理像素，在Retina屏可能是200个物理像素

## 分辨率
* 物理分辨率：屏幕物理像素的总数（如 1920×1080）
* 逻辑分辨率：操作系统或浏览器使用的虚拟分辨率（如 iPhone 13 的逻辑分辨率是 390×844 CSS 像素）

## 设备像素比 (Device Pixel Ratio, DPR)
* 定义：物理像素与逻辑像素的比例系数
  - DPR = 物理像素 / 逻辑像素
* 作用：
  - 解决高密度屏显示问题（如Retina屏）
  - 1个CSS像素对应多个物理像素，实现更精细渲染

* 常见值：
  - 普通屏：DPR=1
  - Retina屏：DPR=2 或 3
  - 4K屏：DPR可能达到4

## 实际开发中的问题与解决方案
* 1px边框问题
  - 问题：在高DPR设备上，border: 1px 会渲染成多个物理像素，看起来过粗
  ```css
    /* 使用媒体查询 + transform */
    @media (-webkit-min-device-pixel-ratio: 2) {
        .thin-border {
            position: relative;
            &::after {
                content: "";
                position: absolute;
                bottom: 0;
                left: 0;
                right: 0;
                height: 1px;
                background: #000;
                transform: scaleY(0.5); /* DPR=2时缩放50% */
                transform-origin: 0 0;
            }
        }
    }
  ```
* 图片模糊问题
  - 问题：普通图片在高DPR设备显示模糊
  - 解决方案：提供多倍图
  ```html
    <!-- 使用srcset适配不同DPR -->
    <img src="image@1x.jpg"
        srcset="image@2x.jpg 2x,
                image@3x.jpg 3x"
        alt="高清图片">
  ```
* 响应式布局适配
  ```js
    // JS获取设备像素比
    const dpr = window.devicePixelRatio;

    // 输出示例：iPhone 13 会返回 3
    console.log("当前设备像素比：", dpr);
  ```
* 如何保持元素宽高比
  - 方案一
  ```html
    <head>
      <style>
        .item{
            margin:0 auto;
            background:red;
            width:50%; // 不知道具体宽度
            aspect-ratio:4 / 3; // 存在兼容性问题，谷歌80+支持
        }
      </style>
    </head>
    <body>
        <div class="item"><div>
    </body>
    
  ```
  - 方案二（大厂方案）
  ```html
    <style>
        .wrapper {
            width: 50%;
            margin: 0 auto;
            background: red;
        }
        .inner {
            width: 100%;
            padding-top: 75%;
            height: 0;
            position: relative;
        }
        .content {
            position: absolute;
            left: 0;
            top: 0;
            width: 100%;
            height: 100%;
            background-color: green;
        }
    </style>

    <body>
        <div class="wrapper">
            <div class="inner">
                <div class="content"></div>
            </div>
        </div>
    </body>

  ```
