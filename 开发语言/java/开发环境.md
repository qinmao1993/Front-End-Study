# java 开发环境

## jdk
* 什么是jdk,jdk 包含了哪些？
  - JRE:Java运行时环境，包含了JVM和核心类库
  - 编译器：javac命令，将你的 .java 源代码文件编译成 .class字节码文件
  - 其他工具：如 java（启动JVM运行程序）、jar（打包工具）、javadoc（生成文档）等

* 如何选择版本和供应商
  + 版本
    - 建议选择Java 8, 11, 17 或 21。这些都是长期支持版本，生态成熟稳定
    - 推荐从 Java 11 或 Java 17 开始
  + 供应商
    - Oracle JDK：最官方的版本，但从Java 11开始，商业用途可能需要付费。个人学习通常免费。
    - OpenJDK：开源的JDK参考实现，完全免费。这是目前大多数开发者和公司的首选。
    - 其他：如Amazon Corretto, Eclipse Temurin等，它们都是基于 OpenJDK 的、经过测试和优化的免费发行版。

* 如何安装JDK（任选一种）？
  + Windows + OpenJDK安装包
    - 下载: 访问 [Eclipse Temurin](https://adoptium.net/zh-CN/temurin/releases) 或 [Azul Zulu](https://www.azul.com/downloads/#zulu)
    - 选择对应的版本（如 Java 17）、操作系统（如 Windows）和架构（如 x64），下载 .msi 安装包

  + Mac + OracleJDK安装包
    - [下载jdk](https://www.oracle.com/java/technologies/downloads/#jdk21-mac)

  + 如何卸载安装包jdk
    ```bash
      # windows 控制面板卸载，在任务栏的搜索框中输入“环境变量”，然后选择“编辑系统环境变量”。
      # 在 “系统变量” 部分，检查以下变量：
      # JAVA_HOME：如果存在，请直接删除它。
      # Path：双击编辑 Path，查找并删除任何指向旧 JDK bin 目录的路径（例如 C:\Program Files\Java\jdk-XX\bin）。
      
      # mac 
      查看已安装的 JDK 列表
      ls /Library/Java/JavaVirtualMachines/
      # 删除
      sudo rm -rf /Library/Java/JavaVirtualMachines/jdk-XX.jdk

    ```

  + Mac + brew

  + jdk的版本管理工具
    - SDKMAN 可以轻松地安装、切换和管理多个JDK版本，也能安装 Maven、Gradle 等工具
    
  + 环境变量配置（理解概念，现代安装包通常自动完成）
    - JAVA_HOME：这个环境变量应该指向你的JDK安装目录（如 C:\Program Files\Eclipse Adoptium\jdk-17.0.7.7-hotspot）。很多IDE和构建工具（如Maven、Gradle）会依赖这个变量。
    - PATH：需要在PATH变量中添加 %JAVA_HOME%\bin，这样你才能在任意目录下使用 java, javac 等命令。

  + 验证安装
    ```bash
      java -version
      javac -version
    ```

## 开发工具
* IntelliJ IDEA
  - 智能、强大、用户体验极佳，被誉为“最好的Java IDE”。社区版免费，终极版收费（功能全面，支持Web开发）。

* Eclipse
  - 老牌、免费开源、插件生态丰富。配置稍显复杂，界面相对老旧

* Visual Studio Code	
  - 轻量级编辑器，通过安装Java插件包可获得不错的Java开发能力。启动快，资源占用小
 
## Visual Studio Code开发 java 项目
* 必需组件
  - Java JDK (推荐 Java 11, 17 或 21)

  - Extension Pack for Java (官方扩展包) 含7个插件

  + Spring Boot Extension Pack (spring web 项目需要) 含3个插件
    > 其中 ​​Spring Initializr​​：官方初始化工具，按需勾选以下常用依赖自动生成项目
    - Spring Web                  # 提供 REST 接口能力
    - MyBatis Framework           # 数据访问层（你也可以用 JPA）
    - Lombok                      # 自动生成构造函数、Getter/Setter、toString() 等模板代码
    - Spring Boot DevTools        # 热部署，修改代码后自动重启
    - MySQL Driver                # 数据库连接驱动
    - Spring Data JPA             # 简化了数据访问层的开发
    - Spring Configuration Processor  # yml提示增强
    - Validation                  # 参数校验注解支持
    - Spring Security             # 鉴权
    - Spring Data Redis           # 做缓存、告警频控等必备
    - WebSocket                   # 实时消息

* 项目创建与管理
  1. 创建项目文件夹并用vscode 打开，右键选择创建项目
  2. 选择项目类型：
    - No build tools - 简单 Java 项目，没有构建工具
    - Maven - 使用 Maven 构建
    - Gradle - 使用 Gradle 构建
    - Spring Boot - Spring Boot 项目

* settings.json 推荐配置
  ```json
    {
        "java.compile.nullAnalysis.mode": "automatic",
        "java.configuration.updateBuildConfiguration": "automatic",
        "java.saveActions.organizeImports": true,
        "java.format.settings.url": ".vscode/java-formatter.xml",
        "java.debug.settings.onBuildFailureProceed": true,
        "java.completion.importOrder": [
            "java",
            "javax",
            "com",
            "org"
        ]
    }
  ```
