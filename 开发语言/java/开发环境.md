# java 开发环境

## jdk
* 什么是jdk,jdk 包含了哪些？
  - JRE:Java运行时环境，包含了JVM和核心类库
  - 编译器：javac命令，将你的 .java 源代码文件编译成 .class字节码文件
  - 其他工具：如 java（启动JVM运行程序）、jar（打包工具）、javadoc（生成文档）等

* 如何选择版本和供应商
  + 版本
    - 建议选择Java 8, 11, 17 或 21。这些都是长期支持版本，生态成熟稳定
    - 推荐从 Java 11 或 Java 17 开始
  + 供应商
    - Oracle JDK：最官方的版本，但从Java 11开始，商业用途可能需要付费。个人学习通常免费。
    - OpenJDK：开源的JDK参考实现，完全免费。这是目前大多数开发者和公司的首选。
    - 其他：如Amazon Corretto, Eclipse Temurin等，它们都是基于OpenJDK的、经过测试和优化的免费发行版。

* 如何安装JDK（任选一种）？
  + Windows + OpenJDK安装包
    - 下载: 访问 [Eclipse Temurin](https://adoptium.net/zh-CN/temurin/releases) 或 [Azul Zulu](https://www.azul.com/downloads/#zulu)
    - 选择对应的版本（如 Java 17）、操作系统（如 Windows）和架构（如 x64），下载 .msi 安装包

  + Mac + OracleJDK安装包
    - [下载jdk](https://www.oracle.com/java/technologies/downloads/#jdk21-mac)

  + Mac + brew

  + jdk的版本管理工具
    - SDKMAN 可以轻松地安装、切换和管理多个JDK版本，也能安装 Maven、Gradle 等工具
    
  + 环境变量配置（理解概念，现代安装包通常自动完成）
    - JAVA_HOME：这个环境变量应该指向你的JDK安装目录（如 C:\Program Files\Eclipse Adoptium\jdk-17.0.7.7-hotspot）。很多IDE和构建工具（如Maven、Gradle）会依赖这个变量。
    - PATH：需要在PATH变量中添加 %JAVA_HOME%\bin，这样你才能在任意目录下使用 java, javac 等命令。

  + 验证安装
    ```bash
      java -version
      javac -version
    ```

## SDKMAN
* 是什么？
  - 是一个强大的命令行工具，用于在类Unix系统（Linux、macOS、WSL）上管理多个软件开发工具包的版本。它就像是Java开发者的"瑞士军刀"
* 核心特性
  - 多版本管理：轻松安装、切换、删除不同版本的JDK和开发工具
  - 一键安装：简化软件安装过程
  - 自动配置：自动设置环境变量
  - 跨平台：支持Linux、macOS、WSL
  - 插件系统：可扩展功能
* 支持的软件类型
  - JDK发行版 (OpenJDK, Oracle JDK, GraalVM等)
  - 构建工具 (Maven, Gradle, SBT等)
  - 开发框架 (Spring Boot, Micronaut, Quarkus等)
  - 其他工具 (Jbang, Leiningen等)
* 安装SDKMAN
  ```bash
    # 使用curl安装
    curl -s "https://get.sdkman.io" | bash

    # 或者使用wget安装
    wget -qO- "https://get.sdkman.io" | bash

    # 初始化SDKMAN
    source "$HOME/.sdkman/bin/sdkman-init.sh"

    # 验证安装
    sdk version

    # 配置 Shell
    source "/Users/xxx/.sdkman/bin/sdkman-init.sh"
  ```
* 查看命令
  ```bash    
    # 列出所有可用的软件包
    sdk list

    # 列出可用的Java版本
    sdk list java

    # 列出可用的Gradle版本
    sdk list gradle

    # 列出可用的Maven版本
    sdk list maven
  ```
* 安装命令
  ```bash
    # 安装最新的稳定版Java
    sdk install java

    # 安装特定版本的Java
    sdk install java 17.0.7-tem

    # 安装指定版本的Gradle
    sdk install gradle 7.6.2

    # 安装指定版本的Maven
    sdk install maven 3.8.6

    # 安装Spring Boot CLI
    sdk install springboot
  ```
* 管理当前使用的版本
  ```bash
    # 查看当前使用的版本
    sdk current

    # 查看特定软件的当前版本
    sdk current java
    sdk current gradle

    # 切换版本（仅在当前shell会话中有效）
    sdk use java 11.0.12-open

    # 设置默认版本
    sdk default java 17.0.7-tem
  ```
* 版本管理
  ```bash
    # 列出已安装的版本
    sdk list java | grep "installed"
    sdk list gradle | grep "installed"

    # 卸载特定版本
    sdk uninstall java 11.0.2-open

    # 卸载当前未使用的所有版本
    sdk flush archives

    # 清理临时文件
    sdk flush temp
  ```
* 更新和升级
  ```bash
    # 检查SDKMAN自身更新
    sdk selfupdate

    # 更新所有已安装软件的候选版本
    sdk update

    # 升级特定软件到最新版本
    sdk upgrade java
    sdk upgrade gradle

    # 升级所有软件
    sdk upgrade
  ```
* .sdkmanrc 文件
  - 在项目根目录创建 .sdkmanrc 文件来自动切换版本
  ```bash
    # 生成 .sdkmanrc 文件（基于当前环境）
    sdk env init

    # 查看 .sdkmanrc 内容
    cat .sdkmanrc
  ```
  - 示例 .sdkmanrc
  ```text
    # Enable auto-env through SDKMAN!
    java=17.0.7-tem
    gradle=7.6.2
  ```
  - 使用环境
  ```bash
    # 在当前目录中启用配置的环境
    sdk env

    # 自动为当前shell启用环境
    sdk env enable

    # 禁用自动环境
    sdk env disable
  ```
* 配置管理
  ```bash
    # 查看当前配置
    sdk config

    # 编辑配置
    sdk config edit
  ```
* 网络问题
  ```bash
    # 如果下载慢，可以设置代理（如果需要）
    export http_proxy=http://your-proxy:port
    export https_proxy=https://your-proxy:port

    # 然后执行安装命令
    sdk install java 17.0.7-tem
  ```

## 开发工具

## 依赖包管理工具 - Maven / Gradle
* 检测是否安装？
  ```bash
    # 检测 Maven 是否安装
    mvn -v
    # 检测 Gradle 是否安装
    gradle -v
  ```

* 安装
  - 下载 ide 会自带
  - 使用 vscode 编辑器需要手动安装 
  ```bash
    # macOS 
    # 使用 Homebrew
    brew install maven
    brew install gradle

    # 或者使用 SDKMAN
    sdk install maven
    sdk install gradle 7.6.2

    # linux

    # Ubuntu/Debian
    sudo apt update
    sudo apt install maven

    # CentOS/RHEL
    sudo yum install maven

    # 使用 SDKMAN (推荐)
    curl -s "https://get.sdkman.io" | bash
    source "$HOME/.sdkman/bin/sdkman-init.sh"
    sdk install gradle 7.6.2
  ```

* Maven
  - 中心化,约定优于配置,所有项目共享
  - 依赖配置文件：pom.xml IDEA已经内置了 Maven，无需单独安装。IDEA会自动下载
   ```xml
    <dependencies>
        <dependency>
            <groupId>org.junit.jupiter</groupId>
            <artifactId>junit-jupiter</artifactId>
            <version>5.9.2</version>
            <scope>test</scope>
        </dependency>
        <dependency>
            <groupId>org.springframework</groupId>
            <artifactId>spring-web</artifactId>
            <version>5.3.0</version>
        </dependency>
    </dependencies>
   ```
  - 依赖存储位置：通常是 ~/.m2/repository
  - 依赖格式:.jar 文件 (编译后的字节码)
  - 依赖解析机制
    ```text
    你的项目 → spring-web 5.3.0 → spring-core 5.3.0
                    ↘ spring-beans 5.3.0
    ```
  - 依赖管理流程
    ```bash
        # 1. 编辑 pom.xml 添加依赖
        # 2. Maven 从中央仓库下载到本地仓库
        mvn dependency:resolve

        # 3. 查看依赖树
        mvn dependency:tree
    ```

* Gradle
  > Gradle 逐渐成为新项目的首选，特别是在Android和大型项目中，Groovy/Kotlin DSL，灵活强大，性能好.继承 Maven 的仓库生态
  - 依赖配置文件：基于 Groovy 或 Kotlin DSL的 build.gradle 或 build.gradle.kts 文件
  ```gradle
    // build.gradle 示例
    plugins {
        id 'java'
        id 'org.springframework.boot' version '2.7.0'
    }

    repositories {
        mavenCentral()
    }

    dependencies {
        implementation 'org.springframework.boot:spring-boot-starter-web:2.7.0'
    }
  ```

* 依赖冲突及解决
  - 遇到版本冲突时，采用最近定义优先策略
  ```xml
    <exclusions>
        <exclusion>
            <groupId>com.fasterxml.jackson.core</groupId>
            <artifactId>jackson-databind</artifactId>
        </exclusion>
    </exclusions>
  ```

* 配置仓库国内加速
  + Maven 加速配置
    - 全局配置：修改 Maven 全局配置文件,文件位置：~/.m2/settings.xml
      ```xml
        <settings>
            <mirrors>
                <!-- 阿里云镜像 -->
                <mirror>
                    <id>aliyunmaven</id>
                    <mirrorOf>*</mirrorOf>
                    <name>阿里云公共仓库</name>
                    <url>https://maven.aliyun.com/repository/public</url>
                </mirror>
                
                <!-- 如果需要使用 Spring Boot 相关依赖 -->
                <mirror>
                    <id>aliyun-spring</id>
                    <mirrorOf>spring-milestones</mirrorOf>
                    <name>阿里云Spring仓库</name>
                    <url>https://maven.aliyun.com/repository/spring</url>
                </mirror>
            </mirrors>
        
            <!-- 可选：配置镜像的优先级 -->
            <profiles>
                <profile>
                    <id>default</id>
                    <repositories>
                        <repository>
                            <id>aliyunmaven</id>
                            <name>aliyun maven</name>
                            <url>https://maven.aliyun.com/repository/public</url>
                            <layout>default</layout>
                            <releases>
                                <enabled>true</enabled>
                            </releases>
                            <snapshots>
                                <enabled>true</enabled>
                            </snapshots>
                        </repository>
                        <repository>
                            <id>aliyun-spring</id>
                            <name>Aliyun Spring Repository</name>
                            <url>https://maven.aliyun.com/repository/spring</url>
                            <releases>
                                <enabled>true</enabled>
                            </releases>
                            <snapshots>
                                <enabled>false</enabled>
                            </snapshots>
                    </repository>
                    </repositories>
                </profile>
            </profiles>
        
            <activeProfiles>
                <activeProfile>default</activeProfile>
            </activeProfiles>
        </settings>
      ```
    - 项目级配置:修改项目 pom.xml
      ```xml
        <project>
            <repositories>
                <repository>
                    <id>aliyun</id>
                    <name>Aliyun Maven Repository</name>
                    <url>https://maven.aliyun.com/repository/public</url>
                    <releases>
                        <enabled>true</enabled>
                    </releases>
                    <snapshots>
                        <enabled>false</enabled>
                    </snapshots>
                </repository>
            </repositories>
            
            <pluginRepositories>
                <pluginRepository>
                    <id>aliyun</id>
                    <name>Aliyun Plugin Repository</name>
                    <url>https://maven.aliyun.com/repository/public</url>
                    <releases>
                        <enabled>true</enabled>
                    </releases>
                    <snapshots>
                        <enabled>false</enabled>
                    </snapshots>
                </pluginRepository>
            </pluginRepositories>
        </project>
      ```
  + Gradle 加速配置
    - 修改项目 build.gradle
      ```gradle
        repositories {
            maven { 
                url 'https://maven.aliyun.com/repository/public/' 
            }
            maven {
                url 'https://maven.aliyun.com/repository/spring/'
            }
            mavenLocal()
            mavenCentral()
        }
        // 对于 buildscript 依赖（如插件）
        buildscript {
            repositories {
                maven { 
                    url 'https://maven.aliyun.com/repository/public/' 
                }
                maven { 
                    url 'https://maven.aliyun.com/repository/gradle-plugin/' 
                }
            }
        }
      ```
  + 清理和重建缓存
    - 当配置生效后，建议清理本地仓库缓存
    ```bash
        # 删除整个本地仓库（彻底）
        rm -rf ~/.m2/repository

        # 或者只删除有问题的依赖
        rm -rf ~/.m2/repository/groupId/artifactId
    ```
  + 验证配置是否生效
    ```bash
      # 查看有效配置
      mvn help:effective-settings

      # 下载依赖时显示详细信息
      mvn -X dependency:resolve
    ```
    
## 编译构建工具
* Maven
  ```bash
    # 1. 编译项目
    mvn compile

    # 2. 运行测试
    mvn test

    # 3. 打包应用
    # 打包成 JAR (可执行库) 或 WAR (Web应用)
    # 平台无关，需要JVM才能运行
    # 依赖会被包含在最终的 jar/war 中
    # 示例：myapp-1.0.0.jar (通常几MB到几十MB)
    mvn package

    # 4. 安装到本地仓库
    mvn install

    # 5. 清理目标文件
    mvn clean
  ```
* Gradle
  - 支持增量构建和构建缓存，构建速度通常更快

## Visual Studio Code开发java项目
* 必需组件
  - Java JDK (推荐 Java 11, 17 或 21)
  - Extension Pack for Java (官方扩展包)
* 项目创建与管理
  1. 创建项目文件夹并用vscode 打开，右键选择创建项目
  2. 选择项目类型：
    - No build tools - 简单 Java 项目
    - Maven - 使用 Maven 构建
    - Gradle - 使用 Gradle 构建
    - Spring Boot - Spring Boot 项目
* settings.json 推荐配置
  ```json
  {
    "java.compile.nullAnalysis.mode": "automatic",
    "java.configuration.updateBuildConfiguration": "automatic",
    "java.saveActions.organizeImports": true,
    "java.format.settings.url": ".vscode/java-formatter.xml",
    "java.debug.settings.onBuildFailureProceed": true,
    "java.completion.importOrder": [
        "java",
        "javax",
        "com",
        "org"
    ]
}
  ```
