# 对象的常用方法
## 对象的遍历
* keys|values|entries
  ```js
    Object.keys(obj).forEach(key=>{})
    Object.values(obj).forEach(value=>{})
    Object.entries(obj).forEach(([key,value])=>{})
  ```
* Object.fromEntries(iterable)
  - iterable：一个可迭代对象（如数组），其元素是键值对数组 [key, value]
  - 用于将键值对列表（通常是数组）转换为一个对象
  - 它是 Object.entries() 的逆操作
  ```js
    // 示例 1：数组转对象
    const entries = [
        ["name", "Alice"],
        ["age", 30],
        ["city", "New York"]
    ];
    const obj = Object.fromEntries(entries);
    console.log(obj);
    // 输出：{ name: "Alice", age: 30, city: "New York" }

    // 示例 2：Map 转对象
    const map = new Map([
        ["key1", "value1"],
        ["key2", "value2"]
    ]);
    const obj = Object.fromEntries(map);
    console.log(obj);
    // 输出：{ key1: "value1", key2: "value2" }

    // 常见场景:转换查询字符串参数
    const queryString = "name=Alice&age=30&city=New+York";
    const params = new URLSearchParams(queryString);

    const obj = Object.fromEntries(params);
    console.log(obj);
    // 输出：{ name: "Alice", age: "30", city: "New York" }

  ```

## 对象合并
* Object.assign()
  ```js
    let target = { a: 1, b: 1 };

    const source1 = { b: 2, c: 2 };
    const source2 = { c: 3 };

    Object.assign(target, source1, source2);
    target // {a:1, b:2, c:3}
  ```

## 检查属性
* hasOwn（推荐）
  - ES2022 引入的静态方法，挂载在 Object 构造函数上
  - 安全可靠，通用性强。适用于所有对象（包括 Object.create(null) 创建的对象）
  ```js
    const user = {
        name: 'Datta',
        age: 25,
    };
    console.log(Object.hasOwn(user, 'name')); // true
    console.log(Object.hasOwn(user, 'age')); // true
    console.log(Object.hasOwn(user, 'location')); // false (property is undefined)
    console.log(Object.hasOwn(user, 'toString')); // false (property is inherited from Object.prototype)
  ```
* hasOwnProperty 
  - 对象可能没有此方法：通过 Object.create(null) 创建的对象没有原型链，不包含 hasOwnProperty，调用会报错。
  ```js
    // obj.hasOwnProperty('propertyName');
    const obj = { a: 1 };
    console.log(obj.hasOwnProperty('a')); // 输出: true
    console.log(obj.hasOwnProperty('b')); // 输出: false
  ``` 
* 与 in 操作符的区别
  - in 操作符会检查对象及其原型链上的属性，而 hasOwnProperty 和 Object.hasOwn 仅检查对象自身的属性。

## 分组
* Object.groupBy() 将数组数据分组为对象
  ```js
    const products = [
        { name: "apples", category: "fruits" },
        { name: "oranges", category: "fruits" },
        { name: "potatoes", category: "vegetables" },
        { name: "bananas", category: "fruits" },
        { name: "carrots", category: "vegetables" },
    ];
    const groupedByCategory = Object.groupBy(products, (product) => product.category);
    console.log(groupedByCategory);
  ```

## 固定对象结构
* Object.seal() 防止意外删除属性
  ```js
    const person = {
        name: 'Datta',
        age: 25,
    };
    // Seal the object: no new properties, no deletions allowed
    Object.seal(person);

    // --- Forbidden Actions (fail silently or throw errors in strict mode) ---
    person.city = 'New York'; // Add new property (fails)
    delete person.age; // Delete existing property (fails)

  ```

* Object.freeze()
  - 防止意外修改,常用于状态管理
  ```js
    const person = {
        firstName: ‘Datta’,
        lastName: ‘Chavhan’,
        age: 25,
    };
    // Freeze the object
    Object.freeze(person);

    // Attempt to change an existing property (will not work)
    person.age = 51;
    person[‘firstName’] = ‘Jane’;

    // Attempt to add a new property (will not work)
    person.eyeColor = ‘blue’;

    // Attempt to delete a property (will not work)
    delete person.lastName;
  ```

## Object.prototype 上的一些方法
* propertyIsEnumerable 判断对象的某个属性是否可枚举
  ```js
    const obj = { a: 1 };
    console.log(obj.propertyIsEnumerable('a')); // 输出: true
    console.log(obj.propertyIsEnumerable('toString')); // 输出: false
  ```
* valueOf 返回指定对象的原始值
  ```js
    // 对于基本数据类型的包装对象（如 Number、String、Boolean），valueOf 方法返回其对应的基本数据类型值。
    const num = new Number(42);
    console.log(num.valueOf()); // 输出: 42

    const str = new String('hello');
    console.log(str.valueOf()); // 输出: 'hello'
  ```
* toString 返回对象的字符串表示形式
  ```js
    const obj = { a: 1 };
    console.log(obj.toString()); // 输出: '[object Object]'

    const arr = [1, 2, 3];
    console.log(arr.toString()); // 输出: '1,2,3'
  ```
* isPrototypeOf、setPrototypeOf、getPrototypeOf
  ```js
    // isPrototypeOf 方法用来判断一个对象是否存在于另一个对象的原型链上
    function Person() {}
    const person = new Person();

    console.log(Person.prototype.isPrototypeOf(person)); // 输出: true
    console.log(Object.prototype.isPrototypeOf(person)); // 输出: true

    // setPrototypeOf 方法设置一个指定对象的原型（即内部 [[Prototype]] 属性）。
    // Object.setPrototypeOf(obj, prototype);
    const proto = { greet() { console.log('Hello!'); } };
    const obj = {};
    Object.setPrototypeOf(obj, proto);
    obj.greet(); // 输出: 'Hello!'

    // getPrototypeOf 方法返回指定对象的原型（即内部 [[Prototype]] 属性）。
    // Object.getPrototypeOf(obj);
    const proto = { greet() { console.log('Hello!'); } };
    const obj = Object.create(proto);
    console.log(Object.getPrototypeOf(obj) === proto); // 输出: true

    // 注意：
    // 1. Object.setPrototypeOf(obj, proto)：用于动态地改变一个对象的原型链，适用于普通对象。
    // 2. obj.prototype.greet：用于定义构造函数的原型方法，适用于构造函数和类。
    // 3. 性能上：定义在构造函数的原型上，性能较好，适用于创建多个实例的场景。

  ```
