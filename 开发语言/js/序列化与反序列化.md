# js 中的序列化与反序列化
通常网络间传输数据或将数据存储到本地存储时，我们会将JavaScript对象转换为字符串，然后在需要时再将其转换回对象，这就是数据序列化与反序列化。JSON.parse() 和 JSON.stringify() 是 JS 中最常用的序列化和反序列化方法。

## JSON.parse 反序列化方法的工作原理与局限性
* 用法示例
  ```js
    const jsonString = '{"name":"张三","age":30,"isActive":true}';
    const obj = JSON.parse(jsonString);
    console.log(obj.name); // 输出：张三
  ```
  
* 存在的问题
  - 性能问题：在处理大型JSON数据时，JSON.parse()可能会导致主线程阻塞，影响用户体验。
  - 数据类型限制：它无法正确处理日期、函数、undefined、NaN、正则表达式等 JavaScript 特有的数据类型。
  - 安全风险：解析不受信任的JSON数据可能带来安全隐患

* 提升反序列化效率的策略
  1. 使用reviver函数处理特殊数据类型
    - JSON.parse()接受第二个参数 reviver，这是一个函数，可以在反序列化过程中转换值
    ```js
        const jsonWithDate = '{"name":"张三","birthDate":"2000-01-01T00:00:00.000Z"}';
        const objWithDate = JSON.parse(jsonWithDate, (key, value) => {
            if (key === 'birthDate') {
                return new Date(value);
            }
            return value;
        });
        console.log(objWithDate.birthDate instanceof Date); // 输出：true
    ```
  2. 流式解析大型JSON
    - 使用流式解析库，如 oboe.js 或 stream-json
  3. 使用二进制格式代替JSON
    - 在某些性能关键的场景中，可以考虑使用二进制格式如 MessagePack、Protocol Buffers 或 BSON
    - 二进制格式通常比JSON更紧凑，解析速度更快，但可读性较差，适用于内部系统通信而非API接口。
    ```js
      import * as msgpack from 'msgpack-lite'

      const encoded=msgpack.encode({name:'张三',age:25})
      const decoded=msgpack.decode(encoded)
      console.log(decoded) // {name:'张三',age:25}
    ```
  4. 使用 Web Workers 在后台解析，避免阻塞主线程

* 第三方文章提到测试数据
  - 小数据集（<10KB）：JSON.parse性能足够好
  - 中等数据集（10KB-1MB）：MessagePack 等二进制格式开始显示优势
  - 大数据集（>1MB）：流式解析或 Web Worker 方案效果最佳

## JSON.stringify
* object 转 string:
  ```js
    // 语法
    JSON.stringify(value: any, replacer?: (this: any, key: string, value: any) => any, space?: string | number): string (+1 overload)
    
    // 第二个参数 null 表示不对结果进行任何替换，第三个参数 2 用于美化输出
    console.log(JSON.stringify(treeData, null, 2))
  ```
